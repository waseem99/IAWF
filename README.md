# IAWF Website Concept

Proposal-stage interactive homepage concept for the International Association of Wildland Fire (IAWF), prepared by Codistan.

This repository contains an audit-informed redesign concept focused on accessibility, global audience clarity, membership growth, event discovery, knowledge/publications, sponsor visibility, and a reusable design system that can extend to event microsites.

> Concept for proposal evaluation. Production implementation is expected to be refined collaboratively with IAWF and implemented in WordPress or the final CMS selected through discovery.

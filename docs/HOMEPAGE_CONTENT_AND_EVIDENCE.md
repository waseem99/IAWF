# IAWF Homepage Concept — Content Structure & Evidence

## Purpose

The homepage is designed to orient a global professional audience quickly, make membership and events easier to act on, elevate knowledge/publications, give sponsors and organizational members visible value, and demonstrate the reusable accessible design system proposed in the RFP.

## Audit-to-design responses embodied in the homepage

- Recurring accessibility indicators → semantic sections, descriptive links, focus-visible states, labelled form controls, keyboard-operable mobile navigation, contrast-aware tokens, no positive tabindex, reduced-motion handling.
- High sampled CLS on current event/content templates → fixed/aspect-ratio media containers and structured event cards without late-loading layout dependencies.
- Inconsistent event/date presentation → event dates/status/location modeled as separate structured fields in the UI.
- Fragmented external journeys → CTAs are explicit about the destination and preserve clear return paths.
- Stale/legacy content risk → homepage content is sourced from current IAWF materials and opportunities are presented with explicit status/timing.
- Event microsite requirement → the same tokens, cards, buttons, navigation and structured content patterns are intentionally reusable for event templates.

## Proposal positioning

The live concept is evidence of Codistan's method and understanding—not a claim that discovery is complete. It should be presented as an illustrative, accessibility-led direction that will be refined with IAWF leadership using official brand assets, content priorities, approved photography and production CMS constraints.
